## Important restore limits
This is an immutable **source-code snapshot**, not a complete point-in-time Supabase database backup.
The connected Supabase tools available for this task do not provide native binary `pg_dump`/database-backup export or Storage object download. This archive therefore does not contain live table rows, Auth password hashes/sessions, database secrets, Cloudflare environment secrets, or Storage file bytes.
The Storage metadata query at snapshot time found zero rows in `storage.objects`; buckets present were `driver-licenses`, `archive-documents`, and `line-report-evidence`.
Live database records remain in the Supabase project and were not changed by this backup operation.

## Recovery checklist
1. Download this branch archive and restore its source to the Git repository.
2. Recreate/restore the Supabase project and apply the migrations in `supabase/migrations` in order.
3. Restore database data and Auth users from a Supabase platform backup/export. Passwords and active sessions may require reset/re-authentication.
4. Recreate the three Storage buckets and restore their objects if any are added later.
5. Restore Cloudflare Pages build settings and environment variables from a separately secured secrets inventory; never put service-role keys or passwords in this repository.
6. Deploy the same source commit and verify login, profiles, drivers, vehicles, letters, attachments, archive, and printing.
